Think Ahead is a very small game based on chess.

It is a chess game, but where you only get to choose between 5 random valid moves in the board position. You can also see what moves your opponent will get if you play each move, so you can anticipate (a little) the game.


## Why?

To practive cshtml templating, HTML rendering from controller, CSS design. All of that without any AI involved.

## How?

Using .NET11, C#, WebAPI controller, cshtml templates, a tiny SQLite database and some useful libraries.

The code is kept as small as possible, no over-engineering, no useless abstraction, only the bare minimum. It feels good sometimes.

If you want to test it, just clone the repository and run the project using `dotnet run --project ThinkAhead`. By default the project is hosted at [https://localhost:7034/](https://localhost:7034/)
